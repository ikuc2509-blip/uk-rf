# УК РФ: справочник — приложение для телефона

Версия 1.0 (черновик 5). Работает без интернета, ставится на главный экран на Android и iPhone.

## Что в папке
- `index.html` — само приложение (все тексты, шрифт и оформление внутри файла).
- `manifest.webmanifest` — название, цвета и иконки приложения.
- `sw.js` — сохраняет приложение на телефоне, чтобы оно открывалось без интернета.
- `icon-*.png`, `apple-touch-icon.png`, `favicon-32.png` — иконки.

## Шаг 2. Установить на телефон
- **Android (Chrome):** откройте адрес → меню ⋮ → **Установить приложение** (или **Добавить на главный экран**).
- **iPhone (Safari):** откройте адрес именно в Safari → кнопка **Поделиться** → **На экран «Домой»** → **Добавить**.

После первого открытия с интернетом приложение работает и офлайн.

## Как обновлять
1. В репозитории загрузите новый `index.html` поверх старого (**Add file → Upload files** → **Commit changes**).
2. В `sw.js` поменяйте строку `VERSION` (например, на `uk-rf-1.1`) и тоже загрузите.
3. На телефоне откройте приложение с интернетом и перезапустите его — подтянется новая версия.

Закладки и выбранная тема хранятся на телефоне и при обновлении не теряются.
